# 🚀 Texting - Lenguaje de Programación en Español

**Texting** es un lenguaje de programación de alto nivel con sintaxis completamente en español, diseñado para ser simple, robusto y autosuficiente.

## Características

- ✅ Sintaxis en español
- ✅ Sin punto y coma obligatorio (se usa salto de línea)
- ✅ Case insensitive (mayúsculas/minúsculas indistintas)
- ✅ Variables dinámicas (no requieren declaración)
- ✅ Tipos: enteros, decimales y cadenas de texto
- ✅ Operaciones aritméticas: +, -, *, /
- ✅ Comparaciones: <, >, <=, >=, ==
- ✅ Estructuras de control: si, repetir, mientras
- ✅ Comentarios con `#`
- ✅ Compilador a código máquina (NASM)
